Rivex

Automate your web tasks effortlessly

Rivex is a smart automation app that lets you create custom tasks to interact with websites automatically — saving you time and clicks. Run tasks that browse, fill forms, or check item stock for you, anytime.

Features

Powerful tools to automate your web tasks

Key features

Create Custom Automation Tasks

Rivex lets you design your own automation tasks using predefined steps that you can fully configure. Choose actions like navigating pages, filling forms, or checking for updates, then set your own timing and conditions—all from your phone.

  • Combine multiple steps into one seamless task
  • Configure parameters to fit any website workflow
  • Save and reuse automation templates easily
Key features

Control and monitor your automations instantly

Stay in control of every running task. Rivex gives you live updates on progress, status, and web interactions directly from the Tasks tab. Start, pause, or stop automations anytime — everything runs transparently in the foreground.

  • View live web previews and task progress
  • Start, pause, or stop with a single tap
  • Reliable automation — runs only when app is active
Key features

Store and manage your website credentials safely

Keep all your website logins organized within Rivex. Each domain can have multiple accounts, letting your automations log in securely when needed—without ever exposing your private data.

  • Create and manage logins per website
  • Autofill credentials for automated tasks
  • Your data stays encrypted and local
